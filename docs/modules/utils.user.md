---
title: User module
---

Create a new user in the deployment. The module is loaded by specifying the
"utils.user" module.

```yaml
name: "Description of the task"
module: utils.user
options:
  name: user
  passwd: crypt(4) password
  groups:
    - sudo
```    

* **name** (string): Description of the task.
* **module** (string): The name of the module to load (utils.user).
* **options** (object): Options to pass to the utils.user module
    * **name** (string): The username of the user to create.
    * **passwd** (string): Crypt(4) string of the user's password. This can be
      generated by running the "openssl passwd" command. And copying and
      pasting the output as a password.
    * **groups**: (list) The list of groups to add the user to when the user
      is created.
